# Library Management System

## Project Overview
A console-based Library Management System developed using Python and Object-Oriented Programming (OOP). The application allows users to manage book records and perform basic library operations through an interactive menu.

## Features
- Add new books with author names and copy quantities.
- Display available books and their details.
- Borrow books with automatic quantity updates.
- Return borrowed books and update inventory.
- Check book availability before borrowing.
- Handle invalid book selections and menu options.

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- Python Dictionaries
- Conditional Statements and Loops

## Concepts Applied
- Classes and Objects
- Constructors
- Methods
- Dictionaries
- Conditional Logic
- Loops

## How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run the following command:

```bash
python library_management.py
```
